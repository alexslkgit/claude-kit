# Work journal

Running record for cross-session continuity: decisions, dead ends, next step. English only.
Gitignored. The user does not read this — it exists so context survives between sessions and
so there is something to inspect when a run goes wrong.

Keep it append-mostly and dated. Prune sections that are finished and no longer inform the
next step; a journal nobody can skim is a journal nobody uses.

## <YYYY-MM-DD> — <task or ticket>

**Goal:** <one sentence, in terms of observable behaviour>

**Decisions:**
- <what was decided, and the reason — especially the reasons that are not obvious from the
  diff, because those are what a future session cannot re-derive>

**Dead ends:**
- <what was tried and did not work, so it is not tried again>

**Open:**
- <what is still unknown, and what would close it>

**Next:**
- <the single next action>
